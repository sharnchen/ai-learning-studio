# AI 學習所 · AI Learning Studio

繁體中文 AI 自學網站，24 個單元，從 AI 基礎到神經網路、生成式 AI、Agent、安全與專題。

## 功能
- 響應式版面、課程搜尋與主題篩選
- 每課觀念、例子、理解練習與測驗，通過測驗後可標記完成
- 梯度下降、CNN 尺寸、分類指標、注意力矩陣四個互動實驗
- 本機筆記與學習進度，支援 JSON 匯出與匯入
- 詞彙庫與官方學習資源連結

## 使用
直接以瀏覽器開啟 index.html。也可執行 `python -m http.server 8000`，開啟 http://localhost:8000。
不需要建置、外部套件、API Key 或後端。localStorage 僅保存於當前瀏覽器與來源，不會跨裝置同步；清除瀏覽器資料前請匯出備份。

## GitHub Pages 發布
1. 建立公開 repository `ai-learning-studio`，將所有檔案上傳到 main 分支根目錄（包含 `.github/workflows/pages.yml`）。
2. Settings → Pages → Source 選 GitHub Actions。
3. Actions → Deploy AI Learning Studio → Run workflow。
4. 完成後從 Pages 設定或部署工作取得網址。

這是教學網站，沒有呼叫遠端模型。互動實驗是簡化的數學示範。課程測驗用於自我檢核，不代表正式能力認證。擴充課程可編輯 lessons.js。

## 擴充學習範圍（2026-11）

- 19 大領域，涵蓋完整的前述 AI 關鍵詞清單。
- 577 個中英文領域詞條，每個都有定義與對應課程。
- 原有 24 個核心單元 + 57 個延伸單元 = 81 個單元；原課程 ID 不變。
- 每個領域分為概念與辨識、方法與連結、應用與取捨三節，含詞條講解、情境案例、實作練習、易混淆觀念及測驗。
- 詞彙庫支援中英文全文搜尋、19 領域篩選、掌握狀態篩選與分頁。
- 學習地圖顯示先備領域、課程完成數及詞條自我檢核數。
- 課程進度與詞條掌握標記分開保存；舊版 JSON 備份可匯入，新版備份包含詞條標記。

`scope.js` 包含領域架構、定義、案例與延伸課程；`keyword-catalog.txt` 為可檢查的完整詞條清單。`index.html` 的腳本順序必須為 lessons.js → scope.js → app.js。

## 逐詞實例、互動與實作

全部 577 個關鍵詞均有獨立撰寫的具體實例、操作任務及驗收標準，可從詞彙卡及延伸課程開啟三頁學習面板：

1. 看實例：情境、定義、專屬練習及可展開參考結果。
2. 互動學習：每詞兩題（情境辨識、結果預測），即時答題回饋；適合數值演示的詞條另附可調參數模擬。
3. 實作指引：領域準備、專屬操作、專屬驗收三步，自我檢核與實作紀錄。

`practice-data.js` 為逐詞內容；`practice-ui.js` 實作三頁面板、進度與數值模擬；`keyword-practice-source.txt` 是編輯用來源。數值模擬在瀏覽器本機執行；外部模型訓練、影音生成與正式系統部署依指引在合適環境另行執行。

學習儲存新增 `termLearning`：雙題通過旗標、三步自我檢核及筆記，隨 JSON 備份匯出／匯入；舊版備份仍可使用。實作勾選是自我紀錄，不是自動執行或能力認證。

完整腳本順序：lessons.js → scope.js → practice-data.js → practice-ui.js → app.js。

## 完整互動實驗室

實驗室使用 `lab-engines.js` 的107種模板：50種實際演算法、47種數值計算、10種流程模擬。全部577個關鍵詞均在 `lab-coverage.json` 明確對應至一個模板，並保留自己的例子、操作目標與實驗紀錄。同機制共享模板，不將577個入口宣稱為577種獨立演算法。

- 實際演算法：小型資料的K-Means、DBSCAN、PCA、卷積／池化、BPE、注意力、RRF檢索、圖搜尋、量化、Q-Learning、訊號處理等。
- 數值計算：形狀與參數、損失、硬體理論下限、浮點格式、記憶體、偏好目標與取捨；面板說明簡化假設。
- 流程模擬：任務規劃、工具授權、MCP連接角色、提示注入防線、版本及部署關卡；不連接外部服務。
- 提供中英文搜尋、領域／方式篩選、模板／關鍵詞兩種瀏覽方式。
- 實驗可調輸入、重設、保存基準並比較、記筆記、下載單次JSON紀錄。
- `labRuns`保存每詞案例的輸入、執行次數、比較摘要與筆記，隨整體學習備份匯入／匯出。原課程、測驗、詞條紀錄保持原有ID。
- 所有運算在瀏覽器以固定小資料或使用者輸入執行；大模型、真實硬體、語音、影像生成等案例明確標為機制示意，未宣稱已執行相應大型模型或系統。

完整腳本順序：lessons.js → scope.js → practice-data.js → practice-ui.js → lab-engines.js → lab-ui.js → app.js。

### 計算過程（Calculation Steps）
所有107個模板及13類詞條內數值示範均記錄實際執行的算術、Math函數、變數更新、計數與比較。結果下方顯示輸入符號、公式、數值代入與逐步結果；每頁60步，全部步驟可下載JSON，單次實驗匯出也包含 `result.calculation`。瀏覽器顯示完整浮點中間值，主結果可能另行四捨五入。流程型實驗亦顯示其實際條件判斷，沒有運算時明示。

計算原始碼位於 `src/practice-ui.js` 與 `src/lab-engines.js`。修改後執行 `npm install`、`npm run build:traces`，產生根目錄同名瀏覽器檔；不要手改產生檔。建置使用Acorn語法樹插入追蹤，保留操作數求值次數與順序；瀏覽器無額外依賴、不使用eval。執行 `node tests/calculation-trace.cjs` 驗證577個案例與未插入追蹤版本結果相同、公式代入、分頁、跳脫與例外清理。

### 圖解學習（Visual Learning）
`visual-guide.js` 提供全部107種模板的四階段概念解說，涵蓋577個詞條案例；82堂課皆加入相關圖解入口。神經元／激活曲線、梯度下降、二維向量、混淆矩陣、K-Means、k-NN、回歸殘差、注意力、框重疊、反向傳播、決策樹與知識圖譜使用專用SVG。其他案例依其實際結果呈現矩陣網格、曲線、比例、狀態流程或數據卡片；不同單位的指標不共用柱高。圖例說明遮罩、色階、座標、截取與簡化假設。可點選步驟或用下一步閱讀，參數更新後重繪結果；不新增遠端服務或模型。執行 `node tests/visual-guide.cjs` 驗證覆蓋、課程入口、步驟切換、輸入同步及標籤轉義。

實驗室採左側輸入、右側即時圖解的並排工作區。概念步驟可展開，數值結果與完整計算保留於下方；桌面捲動時輸入區可保持可見，900px以下自動上下排列。詞條數值示範在寬螢幕亦並排輸入與結果圖。

### 標準數學排版（Mathematical Notation）
使用瀏覽器原生MathML呈現上下分數、根號、次方、上下標、加總、偏導與矩陣。逐步計算改為多行對齊的「公式＝數值代入／＝結果」，條件比較使用等價與推出符號；原始運算表仍可展開核對，JSON保留原值與運算結構。常見AI公式另外提供標準公式區。複雜程式操作若無法可靠等價轉換，保留原文，不推測數學意義；位元XOR也不誤寫成次方。

`math-notation.js`是安全的MathML構造與排版函式；`scripts/build-math.cjs`在建置時以Acorn解析原始表達式，產生 `math-formulas.js`。瀏覽器不載入解析器，不執行公式文字，不依賴外部字型或渲染服務。`npm run build:traces`會一併產生公式對照。執行 `node tests/math-notation.cjs`、`node tests/calculation-trace.cjs`、`node tests/visual-guide.cjs` 驗證數學排版、計算與圖解。

### 題庫、線上組卷與自我測驗（Assessment）
新增 `#assessment` 頁面與 `assessment-data.js`、`assessment-ui.js`：共1322題（577詞條定義、577情境驗收、82課程檢核、65數值計算、21綜合判讀，其中20題多選），涵蓋19領域及全部577詞條。題庫由既有教材與獨立編寫題目組成，難度是教學分級，尚無心理計量校準；不是呼叫LLM即時生成題目。

可搜尋／篩選題庫，依領域、難度、題型、題數（1–100）、固定種子及錯題條件組卷。分層抽題儘量均衡領域並優先避免同詞條重複，池不足時顯示實際可用題數。題目與選項以Fisher–Yates及可重現PRNG洗牌。單選、多選精確比對答案ID；多選須全對且無多選，不給部分分。各題等權、未答計錯，成績以標準數學式顯示計算。

提供交卷後評分的自測模式、逐題檢查的練習模式、限時計時、未答導覽、稍後檢查標記、錯題重練、重測、40次結果紀錄及最多10份未完成試卷。時間依絕對起始時間核對，重新載入或背景分頁返回仍判定到時交卷。答案、題序及選項順序隨 `state.assessment` 納入既有學習紀錄匯出／匯入，舊備份仍可載入；匯入時只接受既知題目與合法選項，成績重新計算。

試卷可列印空白卷或答案解析卷，利用瀏覽器列印另存PDF；另可下載明示包含答案的JSON。所有題目與答案在前端，本功能用於個人學習，未提供監考、身分驗證、多人集中收卷或防作弊。列印及組卷均由學習者在網頁點選。

`node tests/assessment.cjs` 驗證題目唯一性、獨立計算、分層可重現抽題、洗牌答案對應、單／多選精確評分、練習不重複計分、時間到期、備份淨化及空白／解答列印。既有圖解、MathML及計算測試亦保留。

### TronClass Word 匯出
在「題庫與測驗」產生試卷後，或在測驗結果中，點選「匯出 TronClass（Word .docx）」。檔案含單選、多選、依實際選項順序換算的答案、解析／計算過程及難易度；不包含學生作答或題號。
在 TronClass 的題庫／管理測驗題目選擇 Word 匯入，上傳 DOCX 後先預覽辨識結果，確認題數、題型與答案再儲存。格式依先前修正的 TronClass Word 題庫（@@說明、【題型】、答案：、答案解釋：、難易度：），多選答案採 AC 等連續字母。學校版本可能不同，尚未在實際學校帳號完成匯入驗證。

### 梯度上升（Gradient Ascent）
新增課程與詞條、三模式實驗室（凹二次目標、Bernoulli 對數概似、雙臂策略精確預期回報）。輸入與軌跡圖同屏，附標準數學式、逐步更新表與運算追蹤；比較上升 J 與下降 −J 的等價性、學習率造成的震盪／發散及 sigmoid 飽和。新增觀念、單步計算與多選題，支援既有試卷與 TronClass 匯出。參考 MIT 6.790 Policy Gradient。

### 網頁選取與複製限制
全站教材以 CSS 禁止文字選取，並攔截一般 copy／cut／拖曳及 Ctrl／Cmd+A、C、X；使用者輸入框、筆記仍可選取及編輯。既有試卷、TronClass 與紀錄匯出功能保留。這是介面限制，無法阻止截圖、開發者工具或讀取公開原始碼。

### 雙向學習問答（Learning Dialogue）
新增 `#tutor`：學生提問與助教反問。預設為577詞條教材檢索及隨機選項的分支題目；錯誤先提示，正確再延伸提問，不能自動批改自由文字。課程／實驗附情境入口，AI 模式可附上實驗輸入與已計算結果。對話僅保留本分頁。
生成式 AI 需在後端配置 Gemini 或 Groq 金鑰並連線；不在 GitHub Pages 放模型金鑰。部署方式見 [backend/README.md](backend/README.md)。目前未部署後端、未以真實金鑰呼叫模型；免費模型資源與限制於設定中提供官方連結。

Cloudflare正式問答服務已配置於 `ai-learning-studio-api.liesharn.workers.dev`，網站預填端點並提供後端狀態檢查；目前仍需在Worker Secrets填入 `AI_API_KEY` 才能完成真實AI推論驗證。

### 圖形化互動學習
新增 `#explore` 可操作的19領域先備關係圖、領域課程進度環與直接進入課程／實驗的操作面板。首頁提供理解→實驗→自測的學習任務。82堂課加入3張主動回想翻卡與概念／實例配對，配錯提供定義提示、答對提供驗收回饋；不因點擊而標記掌握。107種實驗模板的數值欄位加入同步拖桿，並提供先預測、記住基準、改單一輸入、比較結果的學習流程；沿用原本計算過程與筆記。修正梯度上升課程納入訓練領域的4課進度。支援鍵盤操作及手機堆疊，地圖在窄螢幕可水平捲動。
